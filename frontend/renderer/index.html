当前不是管理员权限，启停网卡会失败。请右键以管理员身份运行。

检测到上次切换未完成，网络可能停在中间状态。

    两种触发方式的区别

    Mode 01 精确 / 偏晚

    系统代理开启

    • 信号ProxyEnable 0 → 1
    • 切换时机打开代理开关的瞬间
    • 误判风险低，只有真开才响
    • 结束条件开关关闭后回切

    不会误判；代价是比代理软件启动晚一拍，代理进程可能已经先连上节点了。

    Mode 02 更早 / 会误判

    代理软件运行

    • 信号进程列表出现匹配的 exe
    • 切换时机代理进程一启动
    • 误判风险中，常驻后台会一直停在热点
    • 结束条件匹配进程全部退出

    时机更早；代价是代理常驻后台（开机自启）时会一直停在热点上，需要自己去关掉自动模式。

    两种都一样：切换必须是硬断 —— 只改路由优先级不会打断已经建立的连接，代理的长连接会继续走原来的链路。
